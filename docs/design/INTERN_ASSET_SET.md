# Intern — approved character asset set

Status: **APPROVED FOR SOMEBODY OKX V4 PROTOTYPING**

Character direction: **Direction 1 — bright-eyed eager Intern**.

The Intern is intentionally the personality inverse of Somebody while remaining in the same visual universe:
- wide-eyed, eager and visibly happy to take work;
- sometimes slightly too eager;
- rounded pale-beige body, dark hand/foot accents and two soft head tufts;
- large glossy eyes and restrained rosy cheeks;
- dark lanyard / Intern badge where the pose allows;
- premium soft-rendered 3D mascot treatment;
- no animal-specific identity and no human anatomy.
