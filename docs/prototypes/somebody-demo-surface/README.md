# Somebody Demo Surface Prototype

Direction: **Executive Mission Control + compact Living Company layer**.

Open `index.html` directly in a modern desktop browser. No server, build step, backend or external dependency is required.

Recommended review size: approximately **1440×900**.

Interactions:

- **Play demo** runs a deterministic canonical mission sequence and pauses at human approval gates instead of silently approving them.
- **Next moment** advances one state at a time.
- **Reset** returns to the received Objective.
- **Approve spend** is available only at seeded approval states.
- click **Growth Operator** or provider nodes to focus the inspector;
- **Decision details** opens the MAKE vs BUY comparison;
- **System X-ray** exposes the secondary causal observability layer;
- outcome levels are selectable.

Everything in this file is seeded prototype/demo data. It does **not** claim a real payment, real provider call, real X publish, production M4 support for every rendered interaction, or blockchain confirmation.

Production data would later come from normalized Objective/Outcome Contract/Requirement/Worker/ManagerialDecision/AuthorizedExecutionIntent/Evidence/Effect/completion projections plus M3 payment lifecycle/readback state.
