# Somebody + Intern Duo Asset Set

These assets are used for shared Somebody + Intern product states.

Included in `docs/design/assets/somebody-intern-duo-assets-approved.zip`:

- `duo-working-bg.webp`
- `duo-working-transparent.webp`
- `duo-walking-bg.webp`
- `duo-walking-transparent.webp`
- `duo-coffee-bg.webp`
- `duo-coffee-transparent.webp`

## Usage

- Working duo — start and active-work states.
- Walking duo — short objective transition.
- Coffee duo — waiting, reassessment and Needs You states.

Transparent variants are preferred inside the product shell.
