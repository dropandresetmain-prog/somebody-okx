# Intern — Character Asset Set

Intern is Somebody's internal worker character.

## Character direction

Intern is intentionally more energetic than Somebody:

- wide-eyed;
- eager;
- optimistic;
- visibly happy to take work;
- rounded pale-beige body;
- dark hand and foot accents;
- two soft head tufts;
- large glossy eyes;
- restrained rosy cheeks;
- dark lanyard / Intern badge where the pose allows;
- soft 3D mascot treatment.

## Asset roles

The current asset set covers:

- neutral / eager;
- avatar;
- working on laptop;
- receiving an assignment;
- presenting a finding;
- waiting / needs input;
- proud / done.

## Usage

Use the approved character references when creating additional poses so Intern remains visually consistent with the current product.
