# Recorded Demo

The recorded Somebody × OKX demo is based on a completed objective run configured to exercise both **MAKE** and **BUY** paths.

## Scenario

The founder asks Somebody to build a launch-week social media plan.

The objective requires:

- company context;
- public research;
- a comparative cross-platform research benchmark;
- a founder-ready final plan.

The scenario uses a simulated cross-platform benchmark so both internal and external paths are visible in one compact run.

## Flow shown

```text
Founder objective
→ Somebody defines the outcome
→ internal work begins
→ missing benchmark is identified
→ external options are evaluated
→ BUY becomes the selected path
→ founder approves $0.01
→ x402 purchase executes
→ X Layer settlement is verified
→ provider result is verified
→ internal work resumes with the new evidence
→ final plan is produced
→ final assessment passes
→ PDF is exported
```

Payments and settlement run on **OKX Testnet**.

## Why this demonstrates the generic engine

The demo configuration creates a compact objective where both MAKE and BUY are useful to show.

The engine itself does not run a fixed MAKE→BUY script.

For every requirement it evaluates current company resources, worker capability, market offerings, provider compatibility, economics, evidence and authority. JEV participates when multiple eligible sourcing options remain. The chosen strategy can therefore differ for other objectives or for the same objective under different company state.
