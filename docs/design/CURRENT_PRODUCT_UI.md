# Current Product UI

The current Somebody × OKX workspace is built around the founder's objective.

## Layout

### Left rail
- Start a new objective
- In progress
- Needs you
- Done

### Main column
- objective header
- Somebody's current update
- Activity
- final deliverable when complete

### Right rail
1. Deliverables
2. Checkpoints
3. OKX Stack

Needs You appears above the right-rail context when founder authority is required.

## Product states

The interface supports:

- starting;
- interpreting;
- working;
- waiting;
- Needs You;
- transaction progress;
- verifying;
- completed;
- blocked.

## Character use

Somebody represents the accountable manager.

Intern represents bounded internal work.

Duo illustrations are used for start, transition and waiting states.

## Product principle

The interface shows meaningful business movement around an objective rather than raw model messages or orchestration traces.
